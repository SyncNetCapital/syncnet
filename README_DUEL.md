# SYNC DUEL // PVP

This build contains two free game modes:

- **Practice** — five deterministic rounds against a practice ghost.
- **Real Duel** — asynchronous peer challenge. The challenger plays first and gets a shareable URL. The recipient plays the exact same seed and sees the challenger score only after finishing.

## Important boundary

The PVP link is a lightweight client-side challenge, not a financial or anti-cheat settlement system. There is no wallet requirement, stake, payment, prize, token transfer, burn or blockchain call.

For any future prize/stake mode, move seed generation, timing validation, score calculation and settlement authorization server-side and complete the necessary compliance work before enabling it.
