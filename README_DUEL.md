# SYNC DUEL // PVP

The V2 launch candidate restores the original free SYNC DUEL game.

- **Practice** — five deterministic rounds against a practice ghost.
- **Real Duel** — asynchronous peer challenge. The challenger plays first and gets a shareable URL. The recipient plays the exact same deterministic seed and sees the challenger score only after finishing.

## Boundary

The challenge is client-side and casual. It is not a financial or anti-cheat settlement system. There is no wallet requirement, stake, payment, prize, token transfer, burn, or redeemable reward. SYNC XP is stored locally, non-transferable, and has no monetary value.

A future prize/stake mode would require server-side seed generation/timing/score verification, settlement controls, abuse prevention, and separate legal/compliance work before it could be enabled.
