Network Sync public beta

The current build can connect a wallet, read live PAR eligibility, construct the exact Network Sync launch calldata, run an eth_call simulation and estimate gas. New transaction execution is temporarily disabled: this build does not call the wallet method used to submit a launch transaction and cannot create a token through the Network Sync interface.

The client still includes receipt-verification logic so a transaction started in an earlier build can be checked without requesting a new transaction. The current public client has not received an independent third-party security audit.

Token name, ticker, logo URL, description, social links and creator tax may be immutable after an eventual launch depending on the underlying contract. Local image uploads are previews unless you provide a persistent public URL. Stable Sync remains preview only; its proposed SYNC burn execution is not enabled in this build.
