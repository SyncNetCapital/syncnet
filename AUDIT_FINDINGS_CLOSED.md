# SyncNet V2.5 — audit findings closed

Build: **SyncNet V2.5 Final Release Candidate** (`v2.5-rc`, 23 Sep 2026). Source audit: `syncnet_v2.5_audit_ro.md` (23 Sep 2026), 21 findings: H1, H2, M1–M4, L1–L15, plus sub-notes N1–N5 and one informational item. Every one is listed below. None was dropped.

## How to read the verification levels

- **FIXED + VERIFIED**: the fix is deterministic SyncNet logic (UI, validation, server function, copy), and automated tests exercise the real code end to end. The only mocks are the chain, the wallet and the providers.
- **FIXED + SIMULATED**: the fix is implemented and tested against a stateful mock of PAR on Robinhood Chain, a mock wallet that signs with real keys, and fake providers. Its final behaviour also depends on a real wallet, RPC, indexer or provider, which is checked at the first live launch (see `FIRST_LIVE_LAUNCH_CHECKLIST.md`).
- **EXTERNAL / CANNOT VERIFY**: the remaining risk sits in a third party that SyncNet cannot inspect.
- **NOT APPLICABLE**: there was no defect to fix.

## Where the test IDs come from

- **PoC F-…**: the audit's own proof-of-concept.
  - `tests/audit/before/` holds the original PoCs and their results against the original V2.5 build: 27/27, 11/11 and 35/35 reproduced, re-run on 23 Sep 2026.
  - `tests/audit/poc-*.mjs` are the same attacks against this build, adapted only where the UI changed. AFTER results:
    - 0 of 16 engine, 0 of 11 server and 0 of 34 page vulnerability checks reproduce.
    - The 10 engine correctness controls and the 5 page "setup" checks still pass, which shows the attacks really ran.
    - Engine PoC: the F-TX1 check was split into "curated markets" and "spot-priced markets", which gives 16 checks instead of 15.
    - Page PoC: 35 BEFORE checks became 34 AFTER checks. Two BEFORE checks that described the attack's precondition became setup checks, one check was split in two, and seven were reworded to be text-neutral because the UI copy changed.
