Non-custodial software and transactions

SyncNet does not custody private keys or seed phrases, and never holds, escrows or forwards your funds. Every transaction is approved in your own wallet. Blockchain transactions are irreversible. A token launch is requested only after a live preflight, a signed intent, a final review, an explicit confirmation and your wallet’s approval; a successful PAR launch is tradable immediately. A simulation does not deploy a token.

“Syncing” a project means selecting one or more assets to form market relationships around that project. A market relationship does not imply endorsement, partnership, ownership or official affiliation between creators or token teams.

Project Passport and Project Marketplace

The Project Passport is SyncNet’s record of a project’s recognised operator. It is operational control inside SyncNet, not ownership of the token contract. The Project Marketplace records signed listings, offers, operator transfers and deal settlement checklists on SyncNet’s backend; every record is authenticated by a free wallet signature, never a transaction or token approval. It is non-custodial and provides no payment guarantee. A completed deal transfers the Project Passport and only the items the listing explicitly names. Token contracts, token supply, locked PAR liquidity and immutable token metadata are never sold and never move. Creator-fee rights move only through the launchpad’s own on-chain transfer, sent from the seller’s wallet and verified by re-reading the chain. ETH payments are checked on-chain; payments in other currencies and off-chain items (domains, repositories, community administration) are settled directly between the parties and must be confirmed by both — SyncNet cannot verify or enforce them, and X accounts are never represented as transferable. Operator history is append-only and prior operators remain permanently visible.

Project Home

A Project Home is an optional page for a project, hosted by SyncNet at /site/<token>. It is a “Project Home on SyncNet”. It must not be described or presented as a project’s “official website”, and it does not make SyncNet a party to, or a representative of, the project.

Activation. Publishing a Project Home needs a one-time activation. Activation currently costs USD 12, paid in SYNC. The SYNC amount is set by the SyncNet reference rate, which SyncNet’s server derives from the canonical PAR SYNC/USDG market when a quote is requested; it is SyncNet’s own reference, not an on-chain price feed. The amount is locked into a quote that is valid for 30 minutes, and only the exact quoted amount, sent to the Project Home payment contract within that time, activates the project. That contract is immutable: 60% of each payment is burned and 40% is converted to USDG for the SyncNet protocol treasury.

No refunds. A successful activation is one-time and non-refundable. The payment contracts have no refund mechanism.

Entitlement. The activation belongs to the project (the token), not to the wallet that paid or to any person. It stays with the project when the Project Passport changes hands.

Control. Only the current Project Passport operator can publish, edit, unpublish, republish, restore or adopt the Project Home, each time with a free wallet signature. A Passport transfer transfers this control. Content published by a previous operator is shown with its links disabled until the new operator adopts it. Edits, unpublishing, republishing, restoring and adoption never require another activation fee.

Duration. Activation does not guarantee permanent hosting. A Project Home remains available for as long as SyncNet operates the Project Home service, subject to these terms.

Operator content. The text, links and images on a Project Home are supplied and controlled by the Project Passport operator. SyncNet does not author, endorse, verify the truth of or guarantee them. Token facts shown on the page are read from Robinhood Chain.
