A parent recognition is a one-sided, signed statement by the root's current operator (or reviewed curator). It is not an endorsement by SyncNet, and the recognized project has not necessarily agreed to it. It ends automatically if the operator changes.

Connection ≠ affiliation · recognition ≠ endorsement

SyncNet shows which markets exist and which recognitions the root's current operator has signed. It does not verify, approve or endorse any project, and it does not publish volume, TVL or fee figures it cannot read truthfully.
